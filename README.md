# CS50 AI – Introduction to Artificial Intelligence with Python

This repository contains my solutions and projects completed as part of **CS50's Introduction to Artificial Intelligence with Python (AI50)** offered by Harvard University.

## Course Overview

The course introduces the fundamental concepts of artificial intelligence and machine learning using Python. It covers search algorithms, knowledge representation, uncertainty, optimization, machine learning, neural networks, and natural language processing.

## What I Learned

Throughout this course, I gained practical experience with:

* Search algorithms

* Probability and Bayesian inference
* Machine learning
* Neural networks and Convolutional Neural Networks (CNNs)
* Natural Language Processing (NLP)
